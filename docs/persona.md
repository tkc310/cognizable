# 読み手のペルソナ

cognizable が想定する読み手像。知能検査（WAIS-IV）の結果を元にしている。検査の数値は、この公開リポジトリには書かない。数値は非公開の場所に記録してある。

## 要点

- 言語理解が強く、ワーキングメモリが弱い。2つの差が大きい。
- 処理速度は平均。配慮の対象は読む速さではなく、保持と注意の持続。
- 規則を読み取る力は強い。空間を組み立てる力は弱い。

## 特性と、整形での対応

| 特性 | 整形での対応 | 関係するルール |
|------|--------------|----------------|
| 概念でまとめる力が最も強い | よく名付けたカテゴリでまとめる。既知の概念との対比を使う | R13、R14、R15 |
| 語彙と知識が平均以上 | 語彙を平易にしすぎない。正確な用語と定義を使う | R7 |
| 数や語を保持しながら処理する力が弱い | 読みながら覚えさせない。差や比率は計算済みの値で書く | R3、R5、R6、R12 |
| 規則を読み取る力は強く、空間を組み立てる力は弱い | 表と一方向の流れ図を使う。配置が入り組んだ図を避ける | D12 |
| 処理速度は平均 | 分量を減らす理由を速さに置かない。保持と注意の持続に配慮を集める | R5、R16 |
| 注意の持続が短い | 1ブロックを2〜3分で読み切れる長さにする。切れ目で中断し、再開できるようにする | R16、D9 |
| 我慢しがちな傾向がある | 「読みにくい」と言われるのを待たない。cognizable の側から1問だけ確かめる | SKILL.md「読み手が言い出すのを待たない」 |

R で始まる ID は `skills/cognizable/SKILL.md` のルール。D で始まる ID は `skills/cognizable/references/design.md` の規則。

## 開始値

次の数値は、調査と読み手像からの推論で決めた開始値。フィードバックの記録で調整する。

| 項目 | 開始値 |
|------|--------|
| 読み手が覚えるか比べる項目 | 4つまで |
| 1ブロックを読む時間 | 2〜3分 |
| L0 の地図のブロック数 | 3〜4個 |
| 地図以外の図のノード数 | 7〜9個 |

## 集団研究との違い

自閉スペクトラム症の集団平均では、処理速度が最も低い（Wilson 2024）。この読み手の処理速度は平均にある。集団研究の知見と読み手の特性が食い違うときは、読み手の特性を優先する。
